# Login Page

A static sign-up / login page built with plain HTML and CSS. It lays out an email and password form, a terms checkbox, and "Sign up with LinkedIn / Twitter / Facebook" buttons for a fictional "Pisocial" brand. There is no JavaScript logic and the form does not submit anywhere; the project is a layout and styling exercise.

## How to run

Open `index.html` directly in a browser, or serve the folder with any static file server. No build step or dependencies are required.

## Files

- `index.html` - page markup
- `assets/styles/index.css` - all styling
- `assets/img/` - icons and illustrations
